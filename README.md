# 🔒 基於 Windows Registry 機制之端點資料隱私一鍵式自動化防護引擎

本專案是一個融合 **作業系統內核運作 (Windows Registry)** 與 **敏捷安全防禦 (Agile Security)** 的端點資安自動化腳本。旨在解決數位創作者或行銷企劃在公共場所移動辦公時，機密多媒體資產與商業原始碼容易面臨端點實體設備被窺探、盜取的實體資安風險。

## 🛠️ 技術實現與架構 (Technical Architecture)

1. **系統級矩陣遮蔽 (Kernel-level Masking)：** 放棄傳統耗費大量 CPU 算力且容易引起注意的第三方加密軟體，本腳本透過修改 Windows 登錄檔（Registry）中 `HKCU` 的 `NoDrives` 點陣圖（Bitmap）數值，直接在 Windows API 底層對指定硬碟分區（Partition）進行隱形遮蔽，達到零記憶體常駐、零算力消耗的極致隱形防護。

2. **動態工作流刷新 (Process Automation)：** 腳本內建 `taskkill` 與自動重啟 `explorer.exe` 核心進程之邏輯，實現免重新開機（Zero-Reboot）的即時防禦切換。使用者僅需透過系統管理員身分執行，即可在 1 秒內切換「啟動防護（隱形）」與「還原解密（顯示）」狀態。

## 📈 專案優勢與商業價值 (Value)

* **零資源佔用與實體隔離：** 在不破壞檔案結構、不佔用硬體運存的前提下，實現最迅捷的實體資料隔離，提供公共場所辦公的終極安全防線。
* **底層架構掌控力：** 展現開發者對於作業系統內核機制（登錄檔控制、進程生命週期管理、二進位點陣圖遮蔽運算）的精準掌控力。
